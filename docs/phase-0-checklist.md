# Validation Checklist

## Hardware
- [ ] Estimated total weight.
- [ ] Wheel diameter selected.
- [ ] Maximum speed selected.
- [ ] Required motor torque calculated.
- [ ] Battery voltage and capacity estimated.
- [ ] Motor driver compatible with startup (stall) current.
- [ ] Onboard computer selected.
- [ ] Microcontroller selected.
- [ ] LiDAR, camera, and IMU preselected.
- [ ] Emergency stop button included.

## Software
- [ ] ROS 2 distribution selected.
- [ ] Operating system selected.
- [ ] Package naming convention defined.
- [ ] TF tree validated.
- [ ] Main topics, services, and actions defined.
- [ ] Simulation strategy defined.
- [ ] Testing strategy defined.
- [ ] Docker strategy defined.

## Project Management
- [ ] Initial GitHub backlog created.
- [ ] GitHub milestones created.
- [ ] Branching strategy defined.
- [ ] Definition of Done (DoD) established.
- [ ] Risks documented.
- [ ] Preliminary budget established.
